# 169 Compact UI Implementation Plan

> For agentic workers: execute bounded parallel work packages, owner integrates and verifies. Current explicit user feedback authorizes this local implementation; no separate approval or Git workflow is required.

**Goal:** 用紧凑无字轮盘、独立求签器物、合并的装扮与虫谱视觉卡片替代重复大窗和文字列表，并核查自然框选捕捉。

**Architecture:** 单一后端和既有交易/计时状态保持；展示路由兼容旧名称，菜单只显示求签/虫瓶/装扮与虫谱/大计时/设置/隐藏/退出。用户随后要求以实际开源参考为准：采用BongoCat历史原作圆角扇瓣，主可见直径约206pt、320pt透明画布容纳外圈缩略图，80pt中央计时；只在hover/accessibility显示名称。

**Tech Stack:** 现有Swift/AppKit/SwiftUI，Python3.12构建；使用macOS内置JavaScriptCore运行原作运动模块，不安装新运行环境。

**Spec:** 本轮用户两张截图和口述反馈。求签只摇签筒、出签，不加上香步骤；自然框选仅被动旁观桌面空白拖选，不把求签当捕网操作，不影响系统鼠标。装扮/虫谱同一页，栏目小标题；真实资产缩略图和果蝇俯视图卡片，详情再显示文字。

## Constraints

- 不读写正式/162/166存档；不关闭现有用户实例。若当前运行则只编译与隐藏验证。
- 同一项目无Git；全部生产资产原件保留，168菜单标志尚未被用户接受，不趁本轮安装。
- 图标用签筒/实际瓶轮廓/衣服，设置齿轮；无独立拉网、移动、调整入口；连续大小留设置。
- 保持真实ID、交易确认、先保存再演出、同日同签、计时单会话。帮助与可访问名称保留。

## Review Focus

- 无字按钮仍具备可访问名称及悬停说明。
- 详情/购买失败/取消不改变所有权、装备或库存。
- 求签先收到成功回执；同日回看与关闭后返回不重抽。
- 不将窗口覆盖/文件拖放/未知事件当桌面捕捉。
- 新尺寸在小屏和边缘内完整可见，面板内容可滚动而不裁切关键按钮。
