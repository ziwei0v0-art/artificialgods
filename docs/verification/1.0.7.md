# 灶神 1.0.7 / build 27 检查

2026-10-08，184菜单栏与退出修复候选。候选构建与139项针对性检查通过，用户桌面实际操作与整体验收仍待确认。

## 本轮结果

- 菜单栏使用macOS原生文字菜单，左键和右键都交由系统菜单处理；“退出”独立于场景隐藏偏好，快捷键为⌘Q。
- 退出立即收起神龛、道童、果蝇、计时工具和提醒，停止输入监听与刷新；迟到的后台回执不会重新显示窗口。
- 后台先有1秒正常保存与退出窗口，仍无响应时发出终止信号，200毫秒后必要时强制结束。管道写入在后台队列，不会阻塞界面或退出监测。
- 清理范围仅为本次创建、已确认归属的worker及其进程组。后台异常退出与重试也先清理旧组；纯僵尸组按已退出处理。
- 正常退出保存计时状态并释放存档锁。恢复模式不改原件；保存失败保留原件与备份；在原子替换前后强退分别保留完整旧档或完整新档。卡死时最后尚未落盘的操作不保证保存。

## 自动验证

三组测试无重复，共139项：

- 后台退出、恢复、存档与完整性：71项，其中17个退出场景使用临时worker和临时存档。
