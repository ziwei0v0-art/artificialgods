- 角色、神龛、图标及其他美术与 1.0.7 逐文件一致；内部应用身份、默认存档位置和玩法保持。

## 桌面操作与存档事件

build29使用独立临时档实际打开了神龛场景和场景菜单。场景菜单获得焦点后，通过界面控制按下⌘Q，原应用及其后台进程均退出，临时存档仍为有效JSON。原生菜单栏的鼠标点击退出尚未完成验证；不能把⌘Q或系统退出请求替代为菜单栏点击验收。

随后对已关闭应用读取界面的操作，导致界面控制工具重新打开了应用，且没有携带临时档参数；这次重开访问了默认存档。已正常关闭重开实例，并保留关闭前后的当前档、备份档和窗口配置副本，未执行回滚或覆盖。没有测试前默认档快照，不能确认短暂运行造成的全部变化。此事件已告知用户；后续退出核验只检查记录的进程与文件，不再读取已关闭应用的界面。

本地证据分别在 `evidence/1.0/186-final-desktop-qa/` 和 `evidence/1.0/186-tool-relaunch-recovery/`；它们含本机状态和存档备份，不进入源码或下载包。正式验收仍需菜单栏鼠标操作、Finder框选、多屏、睡眠恢复和用户视觉确认。
