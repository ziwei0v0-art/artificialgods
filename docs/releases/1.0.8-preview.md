# 灶神 · artificialgods 1.0.8 试玩版

发布文案草稿，尚未上传或公开发布。

一款常驻 Mac 桌面的神龛养成小游戏。供奉、捕虫、陈设和每日求签组成小道童与神龛的日常；独立计时工具支持时钟、倒计时、正计时和番茄钟。

## 适用设备

- Apple Silicon Mac（M 系列芯片）。
- 最低编译目标为 macOS 13.0，旧系统实机验收尚未完成。
- 已内置运行环境，玩家无需另装 Python 或开发工具。
- 目前没有 Windows、Intel Mac 或手机版。

## 本版调整

- 主程序与计时库不再要求构建电脑使用的高版本 macOS。
- 补齐应用和内置运行环境的资源签名校验。
- 补齐游戏获得焦点时的⌘Q完整退出，不再只依赖菜单项上的快捷键标记。
- 保留原生菜单栏“退出”的完整关闭行为，继续保留现有图标、角色、玩法和存档位置。

## 下载与打开

发布时附上游戏 ZIP、对应版本源码 ZIP 和 SHA-256 校验文件。请选择游戏 ZIP；“Source code”是供开发者查看和构建的源码。

解压后，将“灶神.app”放入“应用程序”，再双击打开。已有旧版运行时，请先从菜单栏正常退出。游戏存档不包含在下载包中；直接打开应用使用当前用户的默认游戏存档，独立体验档不会自动合并。

此候选尚未完成 Apple Developer ID 签名和公证，首次打开可能被系统阻止，当前不能宣传为下载后即可顺利运行的正式版。只有确认下载来源可信且包未被修改时，才考虑按 [Apple 的应用打开说明](https://support.apple.com/en-us/102445)处理系统提示。

本版用于自愿的小范围测试。较旧 macOS、另一台 Mac 的首次下载运行，以及菜单栏鼠标退出、Finder 框选、多屏和睡眠恢复仍需实际验收。反馈时请注明 Mac 芯片、系统版本、发生步骤和看到的提示。
